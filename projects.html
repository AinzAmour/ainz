NEXUS-HOMELAB

Enterprise Hybrid Home Lab & Air-Gapped Cyber Threat Sandbox

GitHub Source ↗

Multi-Subnet Docker Network Topology

Architected with 5 discrete Docker bridge networks enforcing least-privilege network containment. Network traffic between enclaves is strictly controlled, and the cyber threat sandbox is air-gapped from host LAN.

Kernel Sysctl & SSH Security Hardening

Host operating system hardened aligned with CIS Level 1 and NIST SP 800-123 benchmarks:

# /etc/sysctl.d/99-homelab-security.conf
# Mitigate SYN Flood DoS Attacks
net.ipv4.tcp_syncookies = 1
net.ipv4.tcp_max_syn_backlog = 2048

# Drop Source-Routed Packets & ICMP Redirect Route Poisoning
net.ipv4.conf.all.accept_source_route = 0
net.ipv4.conf.all.accept_redirects = 0
net.ipv4.conf.all.log_martians = 1

# Enable ASLR & Protect Symlinks/Hardlinks
kernel.randomize_va_space = 2
fs.protected_hardlinks = 1
fs.protected_symlinks = 1
# /etc/ssh/sshd_config.d/hardening.conf
Port 52222
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes # ED25519 Keys Only
Ciphers chacha20-poly1305@openssh.com,aes256-gcm@openssh.com
